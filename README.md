# Chamberlain Nii Amartey — Portfolio

A responsive personal portfolio built with semantic HTML, CSS, and vanilla JavaScript. It presents my background, skills, selected projects, experience, and contact links.

## View locally
1. Download or clone this repository.
2. Open `index.html` in a browser. No build tools or package installation are required.

```bash
git clone https://github.com/nii-amartey/portfolio.git
cd portfolio
open index.html
```

## Features
- Responsive layout with mobile navigation
- Project cards linking to available GitHub repositories
- Accessible navigation states and visible keyboard focus
- Reduced-motion preference support
- Downloadable CV PDF
- Dynamic copyright year
